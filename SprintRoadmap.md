# SprintRoadmap.md

## Sprint 1 --- Universe Foundation

Goal: generate the board the game runs on.

Tasks: - seeded universe generation - star systems - jump graph -
faction placement - home regions - lawless zones - safe regions - basic
metadata

------------------------------------------------------------------------

## Sprint 2 --- Persistence Foundation

Goal: save and reload the universe.

Tasks: - save format - universe serialization - load validation - seed
restore - version handling

------------------------------------------------------------------------

## Sprint 3 --- Economy Core

Goal: locations own real markets.

Tasks: - goods definitions - locations - inventories - production -
consumption - pricing - shortage detection

------------------------------------------------------------------------

## Sprint 4 --- Faction Core

Goal: factions operate in the universe.

Tasks: - faction records - territory - dependencies - basic relations -
logistics pressure

------------------------------------------------------------------------

## Sprint 5 --- Information Layer

Goal: imperfect information.

Tasks: - fog of war - known vs real state - news framework - delayed
information - visibility rules

------------------------------------------------------------------------

## Sprint 6 --- Player / Crew Foundation

Goal: player becomes a real actor in the simulation.

Tasks: - player profile - starter ship - crew records - cargo - travel -
basic orders
